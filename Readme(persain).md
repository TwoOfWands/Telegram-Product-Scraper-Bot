# 🤖 ربات تلگرام اسکرپ محصولات و خروجی Excel

**این پروژه یک ربات تلگرام نوشته‌شده با Python است که به کاربران اجازه می‌دهد نام یک محصول را ارسال کنند و اطلاعات آن محصول از سایت Newegg.com اسکرپ شده و به‌صورت فایل Excel دریافت کنند.**

**نمونه‌کار شخصی** برای نمایش توانایی‌های من در ساخت ربات تلگرام، وب اسکرپینگ، برنامه‌نویسی Async، کار با دیتابیس و تولید فایل Excel پیاده‌سازی شده است.

---

## ✨ امکانات ربات

- دریافت نام محصول از کاربر در تلگرام  
- اسکرپ اطلاعات محصولات از Newegg  
- استخراج مشخصات:  
  - Brand  
  - Color  
  - Price  
  - CPU  
  - Memory  
  - SSD  
  - GPU  
- خروجی گرفتن به صورت فایل Excel `
- استفاده از Async Scraping برای سرعت بالاتر  
- ذخیره اطلاعات کاربران در دیتابیس SQLite  
- رابط کاربری ساده با دکمه‌های تلگرام  

---

## 🛠 تکنولوژی‌های استفاده‌شده

- Python  
- Telegram Bot API (telebot)  
- aiohttp & asyncio  
- BeautifulSoup  
- SQLite  
- XlsxWriter
